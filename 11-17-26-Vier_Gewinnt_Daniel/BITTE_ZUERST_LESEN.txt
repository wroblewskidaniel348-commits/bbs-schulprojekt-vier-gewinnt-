VIER GEWINNT - DANIEL WROBLEWSKI

1. ZIP mit Rechtsklick > Alle extrahieren vollstaendig entpacken.
2. In diesem Ordner VierGewinnt.sln doppelt anklicken.
3. Visual Studio Community 2026 oeffnet das C++-Projekt.
4. Strg + F5 druecken. Visual Studio kompiliert und startet das Spiel.

Kein Terminal, keine BAT-Datei und kein anderer Compiler noetig.
Im Visual Studio Installer muss "Desktopentwicklung mit C++" installiert sein.
Nicht nur main.cpp oeffnen. Immer VierGewinnt.sln oeffnen.

Code ansehen: rechts im Projektmappen-Explorer "Quelldateien" aufklappen.
Falls das Fenster fehlt: Ansicht > Projektmappen-Explorer.

Bei fehlenden C++-Tools: Visual Studio Installer > Aendern >
Desktopentwicklung mit C++ auswaehlen. Danach erneut starten.

Einen Fehler nicht mit "letzten erfolgreichen Build starten" umgehen:
Fehlerliste ansehen und den ersten Fehler mit seinem Code melden.

Weitere Anleitung: docs/Oeffnen_und_GitHub.pdf

WICHTIG: VS Code -> Datei -> Ordner oeffnen -> Vier_Gewinnt_Daniel.
Nach einer Aenderung F5 druecken, damit die aktuelle Version neu gebaut wird.
Nicht eine alte VierGewinnt.exe aus einem frueheren Ordner starten.
Bei Problemen VS Code-Terminal verwenden (nicht Ausgabefenster/Debug-Konsole).
